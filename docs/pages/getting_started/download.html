Para executar: digite o seguinte comando no terminal, substituindo o número da versão conforme necessário:

chmod +x ./instaladorUbuntu24.sh && sudo ./instaladorUbuntu24.sh

Nota: o comando chmod garante que o arquivo bash tenha permissão de execução.
É comum que o sistema solicite sua senha, pois o instalador utiliza comandos com sudo para instalar dependências.
