# UnBeatables

</center>

**UnBeatables** is the Brazilian humanoid robot soccer team from the **University of Brasília (UnB)**, competing in the **Standard Platform League (SPL)** of RoboCup.  
The team is affiliated with the [Automation and Robotics Laboratory (LARA)](http://lara.unb.br/), where research focuses on:

- Localization and mapping
- Computer vision
- Locomotion
- Robot cooperation
- Human-robot interaction
